# 🏷️ دیوار لید — سیستم تجاری جمع‌آوری سرنخ از دیوار

رابط گرافیکی فارسی (وب محلی) + موتور جمع‌آوری چند‌اکانته + ضد بلاک +
مانیتور لحظه‌ای + دیتابیس سرنخ + خروجی اکسل.

## 🚀 اجرا (روی سیستم داخل ایران)
```bash
pip install -r requirements.txt
python -m marketing_divar.web        # مرورگر باز می‌شود: http://localhost:8642
```
یا ویندوز: دابل‌کلیک روی `scripts/run_web.bat`

## 🖥️ استفاده (۷ تب)
1. **داشبورد** — شروع/توقف اسکن + تیک «موارد فعلی هم گرفته شوند؟» + رخدادهای زنده
2. **اکانت‌ها** — لاگین با شماره موبایل + کد پیامکی؛ چند اکانت؛ آزادسازی بعد از کپچا
3. **کلمات کلیدی** — چند کلمه با کاما + انتخاب شهر (یا کل کشور)
4. **پیام‌ها** — قالب پیام چت (شخصی‌سازی با `{title}`) و پیامک (برای آینده)
5. **سرنخ‌ها** — لیست شماره‌دار/فقط‌چت + خروجی اکسل
6. **تنظیمات** — اتصال تلگرام (BotFather)، سهمیه‌ها و تاخیرهای ضد بلاک، سرویس پیامک (آینده)
7. **لاگ‌ها** — گزارش زنده + فایل `logs/divar_app.log` (چرخشی)

## 🛡️ ضد بلاک (به‌صورت خودکار فعال)
| لایه | مقدار پیش‌فرض |
|---|---|
| فاصله شماره‌گیری | ≥ ۱۰ ثانیه + جیتر |
| سقف هر اکانت / کل IP در روز | ۶۰ / ۲۴۰ |
| کپچای یک اکانت | بقیه بدون توقف ادامه می‌دهند + اعلان تلگرام |
| حالت‌ها | captcha / cooldown / relogin / disabled |

## 📦 نسخه نصبی (بدون نیاز به پایتون)
- ویندوز: `scripts/build_exe.bat` → خروجی `dist/DivarLead.exe`
- لینوکس: `scripts/build_exe.sh` → خروجی `dist/DivarLead`
- برای انتشار در GitHub: فایل خروجی را در بخش **Releases** پروژه ضمیمه کنید.

## 🧪 تست‌ها (۳۰ تست — همه پاس)
```bash
python -m unittest discover tests
```
شامل شبیه‌ساز کامل دیوار (`tests/mock_divar.py`) و جریان‌های:
لاگین OTP از وب، کلمات کلیدی چندتایی، قالب پیام، تنظیمات، شروع/توقف مانیتور،
گرفتن شماره، کپچا و ادامه بقیه اکانت‌ها، خروجی CSV، لاگ‌ها.

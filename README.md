# مارکتینگ دیوار — Divar Marketing

رابط گرافیکی فارسی (وب محلی) + موتور جمع‌آوری چند‌اکانته + ضد بلاک +
مانیتور لحظه‌ای + دیتابیس سرنخ + خروجی اکسل.

## 🚀 اجرا (روی سیستم داخل ایران)
```bash
pip install -r requirements.txt
python -m marketing_divar.web        # مرورگر باز می‌شود: http://localhost:8642
```
یا ویندوز: دابل‌کلیک روی `scripts/run_web.bat`


## 🔐 ورود برنامه (v3.3.0)
صفحهٔ ورود داخل خود برنامه است. دفترچه یک فایل CSV کوچک روی همین مخزن است
(`license/ok.csv` — لینک خام). هر مشتری یک سطر. برنامه اول نام کاربری را در سطرها
می‌گردد، بعد رمز، بعد تاریخ انقضا را با **ساعت اینترنت** (هدر Date) می‌سنجد.
بدون اینترنت ورود نیست. «به‌خاطر سپردن» رمز را روی همین رایانه نگه می‌دارد.
تب **اشتراک** نوار روزهای مانده را نشان می‌دهد. بعداً لینک CSV را با
`DIVAR_LICENSE_URL` به هاست خودتان عوض کنید.

نمونه: `demo` / `demo123` تا `2026-09-15`.

## 🖥️ استفاده (۹ تب)
1. **داشبورد** — شروع/توقف اسکن + تیک «موارد فعلی هم گرفته شوند؟» + پیامک/چت خودکار + رخدادهای زنده
2. **اکانت‌ها** — پروفایل پایدار Chromium برای هر اکانت؛ با باز شدن، سه تب دیوار / شیپور / رینگ در همان پروفایل
3. **کلمات کلیدی** — دسته واحد (نگاشت خودکار شیپور/رینگ) + چند شهر + کلمه اختیاری + بازه قیمت و VIP + شکارچی
4. **پیام‌ها** — قالب چت با `{title}` + قالب پیامک ملی‌پیامک + قالب استعلام قیمت
5. **سرنخ‌ها** — شماره‌دار / فقط‌چت / شکارچی / معیوب / پاسخ‌ها + خروجی اکسل جدا
6. **ربات هوشمند** — وضعیت مدل محلی، چت خودکار، صندوق پاسخ، شکارچی
7. **تنظیمات** — سوییچ دیوار/شیپور/رینگ، تلگرام، سهمیه IP، ملی‌پیامک رسمی
8. **اشتراک** — نام، طرح، نوار روزهای مانده
9. **لاگ‌ها** — گزارش زنده + فایل `logs/divar_app.log` (چرخشی)

## ✉️ پیامک و چت (ارسال خودکار)
- **پیامک (ملی‌پیامک):** در تب «تنظیمات» نام کاربری، رمز (یا کلید API) و خط اختصاصی
  را وارد کنید؛ سپس «بررسی موجودی» و «ارسال آزمایشی» (با یک شماره) بزنید. تیک
  «ارسال خودکار» = به محض پیدا شدن شماره، متن قالب تب «پیام‌ها» همان لحظه می‌رود.
- **چت دیوار (فقط‌چت):** پیش‌فرض **نیمه‌خودکار** است (متن آماده + باز شدن چت + یک کلیک
  ارسال — ضد بن). گزینهٔ «ارسال خودکار چت» در تب «پیام‌ها» موجود است ولی خاموش است؛
  ⚠️ این مسیر غیررسمی و پرریسک است. سقف روزانه و تأخیر دارد و هر شکست خودکار به جریان
  نیمه‌خودکار برمی‌گردد.
- **متغیرها (چت و پیامک):** `{title}`، `{subtitle}`، `{city}`، `{keyword}`، `{price}`،
  `{published_at}`، `{url}` و گردونهٔ `{greeting}` / `{closing}` (هر بار متفاوت) —
  هر پیام با اطلاعات همان آگهی شخصی‌سازی می‌شود تا متن‌ها یکسان نباشند.
- **چرخش اکانت چت:** ارسال چت بین اکانت‌های فعال می‌چرخد تا یک اکانت مسدود نشود؛
  ردپای هر ارسال (اکانت + زمان) در تب سرنخ‌ها و جدول operations ثبت می‌شود.
- **گزارش تحویل پیامک:** RecId ذخیره می‌شود و با `GetDeliveries2` وضعیت تحویل
  (تحویل/ناموفق/در انتظار) خوانده می‌شود (دکمه در تنظیمات + نمایش در سرنخ‌ها).
  نکته: چت دیوار رسید رسمی تحویل ندارد — فقط پذیرش ارسال ثبت می‌شود.

## 🔑 کلمه کلیدی، شهر، دسته و قیمت
در تب «کلمات کلیدی» چند شهر و یک دسته واحد را انتخاب می‌کنید (اسلاگ شیپور/رینگ خودکار نگاشت می‌شود).
فقط دسته = همهٔ آگهی‌های آن لیست. بازه قیمت (میلیون تومان) و تیک هشدار ویژه اختیاری است.
شکارچی خودرو شاسی/دوررنگ/تصادف را از متن آگهی جدا می‌کند تا قیمت پایین معیوب شکار عالی نشود.
مدل GGUF هنگام نصب کنار فایل نصبی دانلود و کنار برنامه نصب می‌شود (داخل گیت نیست).

## v1.4.0 — ریشه‌یابی «همه‌چیز صفر» (۱۴۰۵/۰۶)

  برنامه خودش یک‌بار بدون پروکسی (اتصال مستقیم — درست برای IP ایران) تلاش می‌کند.

- پیام ۴۰۳ دیوار راهنمای صریح دارد: «VPN را خاموش کنید — دیوار فقط با IP ایران».
- ۴۰ تست (۲ بار): همه پاس؛ سناریوی کامل (لاگین + موارد فعلی + شروع) سرتاسری تأیید شد.

## v1.5.0 — چند-مسیری اتصال + بررسی اتصال کامل (۱۴۰۵/۰۶)
- **۴ مسیر اتصال پشت‌سرهم:** requests با پروکسی سیستم → requests مستقیم → httpx → urllib؛
  مسیر برنده به‌خاطر سپرده می‌شود (sticky). حداقل یکی در هر شرایطی جواب می‌دهد.
- **راه نجات جستجو (تأیید زنده ۱۴۰۵/۰۶):** `GET /v8/web-search` الان
  `BLOCKING_VIEW` می‌دهد؛ برنامه HTML عمومی `divar.ir/s/…` و در صورت امکان
  `POST /v8/search` را امتحان می‌کند. جزئیات آگهی از `posts-v2` (بدون لاگین).
- **دکمه «بررسی اتصال کامل» در تنظیمات:** DNS → اتصال → جستجو → آگهی واقعی
  (عنوان+متن+مکان کلمه کلیدی) → شماره بدون لاگین (آزمایش) → شماره با اکانت →
  دسترسی چت (بهترین‌حال) → وضعیت پروکسی؛ هر قدم ✓/✗ + زمان + جزئیات.
- **لاگ فوق‌دقیق:** هر درخواست HTTP با مسیر استفاده‌شده و زمان پاسخ، هر سرنخ
  جدید با مکان کلمه (عنوان/متن) در پنل رخدادها.
- ۴۶ تست (۲ بار): همه پاس.

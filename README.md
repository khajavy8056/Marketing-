# مارکتینگ دیوار — Divar Marketing

رابط گرافیکی فارسی (وب محلی) + موتور جمع‌آوری چند‌اکانته + ضد بلاک +
مانیتور لحظه‌ای + دیتابیس سرنخ + خروجی اکسل.

## 🚀 اجرا (روی سیستم داخل ایران)
```bash
pip install -r requirements.txt
python -m marketing_divar.web        # مرورگر باز می‌شود: http://localhost:8642
```
یا ویندوز: دابل‌کلیک روی `scripts/run_web.bat`

## 🖥️ استفاده (۷ تب)
1. **داشبورد** — شروع/توقف اسکن + تیک «موارد فعلی هم گرفته شوند؟» + رخدادهای زنده
2. **اکانت‌ها** — لاگین با شماره موبایل + کد پیامکی؛ چند اکانت؛ آزادسازی بعد از کپچا
3. **کلمات کلیدی** — دسته و زیردسته دیوار + شهر دراپ‌داون + کلمه اختیاری + بازه قیمت و VIP
4. **پیام‌ها** — قالب چت نیمه‌خودکار + قالب پیامک ملی‌پیامک (ارسال خودکار اختیاری)
5. **سرنخ‌ها** — لیست شماره‌دار/فقط‌چت + خروجی اکسل با تاریخ و ساعت استخراج
6. **تنظیمات** — تلگرام (ربات با دکمه و اکسل)، سهمیه IP، ملی‌پیامک رسمی
7. **لاگ‌ها** — گزارش زنده + فایل `logs/divar_app.log` (چرخشی)

## 🛡️ ضد بلاک (به‌صورت خودکار فعال)
| لایه | مقدار پیش‌فرض |
|---|---|
| فاصله شماره‌گیری | ≥ ۱۰ ثانیه + جیتر |
| سقف هر اکانت / کل IP در روز | ۱۲۹ نرم (تا کپچا ادامه) / ۲۴۰ |
| کپچای یک اکانت | بقیه بدون توقف ادامه می‌دهند + اعلان تلگرام |
| حالت‌ها | captcha / cooldown / relogin / disabled |

فقط دسته = همهٔ آگهی‌های آن لیست. بازه قیمت (میلیون تومان) و تیک هشدار ویژه اختیاری است.

## 📦 ساخت Setup تک‌فایل روی ویندوز
این مخزن از لینوکس فایل exe ویندوز تحویل نمی‌دهد. روی همان ویندوز:
1. اول یک‌بار `Install-and-Run.bat` را نصب کنید
2. بعد `ساخت-نصب-استاندارد.bat` را دابل‌کلیک کنید
3. خروجی: `dist\\DivarLead.exe` و کپی روی دسکتاپ

## 📥 دانلود و اجرای سریع روی ویندوز (نسخه ۲.۱.۱۰)
1. از [Releases v2.1.10](https://github.com/khajavy8056/Marketing-/releases/tag/v2.1.10) فایل **Source code (zip)** را دانلود کنید
   یا مستقیم: https://github.com/khajavy8056/Marketing-/archive/refs/tags/v2.1.10.zip
2. روی زیپ **راست‌کلیک → Extract All** (از داخل پنجرهٔ زیپ اجرا نکنید)
3. داخل پوشهٔ استخراج‌شده روی **`Install-and-Run.bat`** دابل‌کلیک کنید
4. پنجرهٔ نصب با نوار پیشرفت باز می‌شود؛ اگر باز نشد همان CMD نصب را ادامه می‌دهد و بسته نمی‌شود
5. بعد از نصب، میانبر دسکتاپ **خواجوی لید** برنامه را باز می‌کند
6. مرورگر: `http://localhost:8642` — اکانت، کلمات، تلگرام و ملی‌پیامک را یک‌بار تنظیم کنید
7. بستن و باز کردن دوباره تنظیمات را پاک نمی‌کند (`%LOCALAPPDATA%\\KhajavyLead`)
8. اتصال واقعی به دیوار فقط با **IP ایران**

نسخه تک‌فایل Setup: روی ویندوز `ساخت-نصب-استاندارد.bat` → `dist/DivarMarketing-Setup.exe`

## v1.4.0 — ریشه‌یابی «همه‌چیز صفر» (۱۴۰۵/۰۶)
- **خودترمیمی پروکسی:** روی ویندوز اگر VPN/پروکسی سیستم فعال باشد و دیوار را قطع کند،
  برنامه خودش یک‌بار بدون پروکسی (اتصال مستقیم — درست برای IP ایران) تلاش می‌کند.
- **شفافیت کامل رخدادها:** شروع هر دور، خطای جستجو (+ راهنمای VPN/اینترنت)، شماره‌های
  پیداشده، کپچا/بلاک/سهمیه — همه در پنل «رخدادها» دیده می‌شوند؛ دیگر «بی‌صفر و بی‌خبر» نیست.
- پیام ۴۰۳ دیوار راهنمای صریح دارد: «VPN را خاموش کنید — دیوار فقط با IP ایران».
- ۴۰ تست (۲ بار): همه پاس؛ سناریوی کامل (لاگین + موارد فعلی + شروع) سرتاسری تأیید شد.

## v1.5.0 — چند-مسیری اتصال + بررسی اتصال کامل (۱۴۰۵/۰۶)
- **۴ مسیر اتصال پشت‌سرهم:** requests با پروکسی سیستم → requests مستقیم → httpx → urllib؛
  مسیر برنده به‌خاطر سپرده می‌شود (sticky). حداقل یکی در هر شرایطی جواب می‌دهد.
- **راه نجات جستجو (تأیید زنده ۱۴۰۵/۰۶):** `GET /v8/web-search` الان
  `BLOCKING_VIEW` می‌دهد؛ برنامه HTML عمومی `divar.ir/s/…` و در صورت امکان
  `POST /v8/search` را امتحان می‌کند. جزئیات آگهی از `posts-v2` (بدون لاگین).
- **دکمه «بررسی اتصال کامل» در تنظیمات:** DNS → اتصال → جستجو → آگهی واقعی
  (عنوان+متن+مکان کلمه کلیدی) → شماره بدون لاگین (آزمایش) → شماره با اکانت →
  دسترسی چت (بهترین‌حال) → وضعیت پروکسی؛ هر قدم ✓/✗ + زمان + جزئیات.
- **لاگ فوق‌دقیق:** هر درخواست HTTP با مسیر استفاده‌شده و زمان پاسخ، هر سرنخ
  جدید با مکان کلمه (عنوان/متن) در پنل رخدادها.
- ۴۶ تست (۲ بار): همه پاس.

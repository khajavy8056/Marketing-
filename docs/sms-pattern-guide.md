# 📱 راهنمای ارسال پیامک با پترن (خط خدماتی) ملی‌پیامک

> تاریخ: ۱۴۰۵/۰۶/۰۶ — نسخهٔ ۲.۳.۰

از نسخهٔ ۲.۳.۰ برنامه دو روش ارسال پیامک را پشتیبانی می‌کند:

| روش | مسیر API | نیاز به خط اختصاصی | به لیست سیاه می‌رسد؟ |
|---|---|---|---|
| **خط اختصاصی** | `SendSMS` | ✅ بله | ❌ نه |
| **پترن (خط خدماتی)** | `BaseServiceNumber` | ❌ نه | ✅ بله |

پترن فقط به **نام کاربری + رمز پنل + کد پترن (bodyId)** نیاز دارد و شمارهٔ خط اختصاصی لازم ندارد.

---

## ۱) پترن چیست و چرا؟

پترن یعنی **متن از قبل در پنل ملی‌پیامک ثبت و توسط واحد اداری تأیید می‌شود**؛
موقع ارسال فقط **مقادیر متغیرها** (مثل عنوان آگهی، شهر، قیمت) را می‌فرستید.
چون متن تأییدشده است، سرعت ارسال بالاست و **به شماره‌های لیست سیاه هم می‌رسد**.

## ۲) قوانین مهم تأیید پترن (که باید رعایت شود)

طبق مستندات رسمی ملی‌پیامک:

1. **فقط خدماتی / اطلاع‌رسانی** — پترن برای تبلیغات نیست. «این سرویس تنها برای
   پیامک‌های خدماتی و اطلاع‌رسانی ارائه شده؛ اگر هدف تبلیغات است باید از خطوط
   تبلیغاتی استفاده کنید.»
2. **حتماً متغیر داشته باشد** — پترنِ بدون متغیر رد می‌شود.
3. **لینک نگذارید** — وجود هر لینک در متن پترن رد می‌شود.
4. **HTML و کاراکترهای نامعتبر** ممنوع.
5. **متن گمراه‌کننده/مغایر قانون** رد می‌شود.

> ⚠️ اگر متن شما «تبلیغاتی» تشخیص داده شود، پترن تأیید نمی‌شود. برای ارسال
> بازاریابی سرد (cold outreach)، روش **خط اختصاصی** امن‌تر و قطعی‌تر است.

## ۳) گام‌به‌گام در پنل ملی‌پیامک

1. وارد پنل `melipayamak.com` شوید.
2. به بخش **«پیامک پترن» / «الگوی متن» / «وب‌سرویس خدماتی»** بروید.
3. **الگوی جدید** بسازید و متن را با متغیر ثبت کنید (مطابق نمونهٔ پایین).
4. قوانین را تیک بزنید و **ثبت** کنید — متن به واحد اداری می‌رود.
5. بعد از **تأیید**، یک **کد پترن (bodyId)** به شما داده می‌شود.
6. همان کد را در برنامه (تب تنظیمات → ملی‌پیامک → «کد پترن») وارد کنید.

## ۴) نمونه متن پترن پیشنهادی (۲ متغیر: عنوان + شهر)

متن را به‌صورت اطلاع‌رسانی و محترمانه بنویسید (نه تبلیغ صریح):

```
کاربر گرامی، در خصوص آگهی «%title%» شما در %city% درخواست تماس ثبت شده است.
لطفاً در صورت تمایل پاسخگو باشید.
```

در پنل ملی‌پیامک متغیرها معمولاً به شکل `%title%` یا جای‌خالی مشخص می‌شوند؛
ترتیب متغیرها را یادداشت کنید (اینجا: اول عنوان، بعد شهر).

**در برنامه، «ترتیب متغیرهای پترن» را مطابق همان ترتیب بنویسید:**
```
title,city
```

### نمونهٔ دوم (۳ متغیر: عنوان + شهر + قیمت)

```
کاربر گرامی، دربارهٔ آگهی «%title%» در %city% با قیمت %price% تومان پیامی برای شما ثبت شده است.
```
ترتیب در برنامه:
```
title,city,price
```

## ۵) فیلدهای قابل استفاده به‌عنوان متغیر پترن

| نام | معنی |
|---|---|
| `title` | عنوان آگهی |
| `city` | شهر |
| `price` | قیمت (خوانا، مثلاً «50 میلیون») |
| `subtitle` | توضیح میانی |
| `keyword` | کلمهٔ کلیدی/دسته |
| `published_at` | زمان انتشار آگهی |
| `url` | لینک آگهی (⚠️ در متن پترن لینک رد می‌شود؛ بهتر است استفاده نکنید) |

## ۶) خطاهای رایج و معنی

| کد | معنی | راه‌حل |
|---|---|---|
| `-5` | کد پترن صحیح نیست / تأیید نشده | صبر کنید تا پترن تأیید شود یا کد را اصلاح کنید |
| `-6` | تعداد/ترتیب متغیرها با پترن نمی‌خواند | «ترتیب متغیرهای پترن» را با متن پترن هم‌خوان کنید |
| `-2` | کد پترن درج نشده | «کد پترن» را وارد کنید |
| `0` | نام کاربری/رمز اشتباه | نام کاربری و رمز پنل را چک کنید |
| `2` | اعتبار کافی نیست | پنل را شارژ کنید |
| `7` | کلمهٔ فیلترشده | متن پترن را تغییر دهید |
| `11` | ارسال نشد | با پشتیبانی تماس بگیرید |

# شکارچی حرفه‌ای V2 — آنالیزور قیمت با بازار سالم + مذاکره انسانی

## مشکل قبلی شما (به زبان خودتان)

> «حتی من الان واقعاً اون قیمت اولین قیمتی که داره از کارم می‌گیره نمی‌تونیم قیمت بگیریم و باید سیستم به شکل باشه که ببینیم باید سیستم مدل ما نسبت به محصول شناسایی کنه بگرده اول داخل قیمتش چه جوریه بهترین مدلشو که سالم‌ترین مدل باشه»

> «مذاکره کنید ولی مذاکره باعث شده باشه که یارو متوجه نشه ربات داره صحبت می‌کنه خیلی تعاملی خیلی قشنگ نتیجه‌ای که رسید اون موقع آقا میگه که به آلارم میده ویژه میده میگه آقا من مذاکره کردم بعد مذاکره به این قیمت»

## راه‌حل حرفه‌ای پیاده‌شده

### 1) هسته آنالیزور — بازار سالم نه میانگین خام

**قبل:** میانه خام ۵ نمونه (مثلاً ۳۲۰M) → قیمت هدف ۲۵۰M → ۲۲% تخفیف → great

**مشکل:** اگر نمونه‌ها خودشان معیوب باشند (دوررنگ، شاسی ضربه)، میانه پایین می‌آید و شکار واقعی گم می‌شود.

**حالا (hunter_analyzer.py):**

1. **شناسایی محصول:**
   - `identify_product(text, category, keyword)` → برند، مدل، سال، کارکرد از متن
   - برای خودرو: سال شمسی/میلادی + کارکرد + شاسی + رنگ + تصادف
   - برای موبایل: برند (اپل/سامسونگ/شیائومی) + وضعیت + باتری + رجیستری
   - برای لپ‌تاپ: SSD/HDD + رم + باتری + صفحه

2. **نرمال‌سازی به سالم‌ترین مدل:**
   - هر نمونه: `adj = adjustment_pct(flags) + mileage_adjustment`
   - `healthy_eq = price / (1 + adj/100)` — مثلاً ۲۰۰M دوررنگ -۱۴% → ۲۰۰/۰.۸۶ = ۲۳۲.۵M معادل سالم
   - این یعنی همه قیمت‌ها را به «سالم» تبدیل می‌کنیم، بعد میانه می‌گیریم

3. **حذف پرت با IQR:**
   - Q1, Q3, IQR → حذف خارج از [Q1-1.5*IQR, Q3+1.5*IQR]
   - حداقل ۶۰% نمونه بماند
   - صدک‌ها: p10, p25, p75, p90 → اگر قیمت زیر p10 باشد → حتی اگر آستانه نرسد، good

4. **ارزیابی هدف:**
   - `fair = healthy_median * (1 + adj_flags + adj_mileage + adj_year)`
   - `adj_year`: هر سال ۵% افت نسبت به امسال، ولی نصف اثر برای جلوگیری از سخت‌گیری
   - `discount = (fair - price)/fair`
   - `confidence`: بر اساس تعداد نمونه (۱۰+ → +۰.۲)، داشتن سال/کارکرد (+۰.۱)، پرچم‌ها (+۰.۰۵)
   - سطح: good (۱۰%)، great (۱۸%)، suspicious (۴۸%) + تقویت با p10

5. **مثال ۱۰۰km vs صفر:**
   - صفر خشک +۳% → fair بالاتر
   - ۱۰۰km +۳% (هنوز خیلی کم) → fair تقریباً برابر صفر
   - پس ۱۰۰km با قیمت ۲۵۰M در حالی که صفر ۳۲۰M → ۲۲% زیر منصفانه → great
   - این دقیقاً خواسته شما: «۱۰۰km ممکن است هنوز شکار باشد»

6. **مثال دوررنگ با قیمت مناسب هنوز شکار:**
   - میانه سالم ۳۲۰M
   - دوررنگ -۱۴% → fair ۲۷۵M
   - قیمت ۲۰۰M → ۲۷% زیر fair → great → VIP
   - حتی دوررنگ اگر خیلی ارزان باشد شکار است — کاسب حرفه‌ای این را می‌خواهد

### 2) مذاکره‌گر انسانی — ضد تشخیص ربات

**ماژول جدید: hunter_negotiator.py**

#### استعلام جای خالی (inquiry)
- قبل: «1) مدل چند است؟ 2) شاسی سالم است؟» — ربات‌گونه
- حالا: مدل Qwen اگر آماده باشد با پرامپت:
  > «تو یک خریدار معمولی و مودب ایرانی هستی، نه دلال، نه ربات. از روی سوالات ثابت زیر، یک پیام کوتاه، طبیعی، عامیانه ولی مودب بنویس...»
- fallback قاعده‌ای انسانی:
  - `سلام عزیز، وقت بخیر 🌹 برای آگهی «پراید 1399»: 1) مدل چند است؟ لطف می‌کنید جواب بدید`
  - هر بار greeting/closing متفاوت: «سلام، وقت بخیر»، «درود»، «سلام بزرگوار» + «ممنون از وقتی که می‌ذارید 🙏»، «سپاس 🌹»

#### مذاکره چندمرحله‌ای
**مراحل:**
- `opener`: تشکر + اشاره به بازار + سوال تخفیف
  - «ممنون بابت اطلاعات کامل 🙏، من چند مورد مشابه دیدم، قیمت‌ها حول و حوش ۳۲۰ میلیون بود. برای آگهی «پراید ۱۳۹۹» قیمتتون مقداری قابل مذاکره هست؟»
- `offer`: پیشنهاد ۵-۸% کمتر + نقد آماده
  - «ممنون بابت پاسختون. راستش بودجه من حدود ۲۳۰ میلیون هست. اگر براتون مقدوره با این قیمت معامله کنیم، من امروز نقد آماده‌ام.»
- `final`: پیشنهاد نهایی + هماهنگی
  - «خیلی ممنون از وقتی که گذاشتید. من می‌تونم تا ۲۳۵ میلیون نقد همین امروز اقدام کنم. اگر موافقید بفرمایید تا هماهنگ کنیم.»

**ویژگی ضد ربات:**
- لحن تهرانی، خودمانی، مودب، نه رسمی خشک، نه دلال
- از «داداش»، «بزرگوار»، «عزیز» بسته به لحن فروشنده (در نسخه بعدی با تحلیل sentiment)
- تاخیر طبیعی بین پیام‌ها (در monitor با jitter)
- هر پیام متفاوت — greeting/closing گردونه‌ای

**تحلیل پاسخ فروشنده:**
- `analyze_negotiation_reply(text)` → `agreed` (باشه، قبوله، اوکی، حله)، `refused` (نه، نمیشه، تخفیف نداره)، `new_price` (استخراج تومان)
- اگر توافق → `negotiated` → VIP
- اگر رد و ۲ دور گذشته → `refused` → توقف

**ادامه مذاکره:**
- `should_continue_negotiation(history, eval)` → حداکثر ۳ پیام خریدار
- اگر فروشنده قیمت جدید داد (مثلاً ۲۴۰M) → آن را به عنوان `negotiated_price` ذخیره، دوباره ارزیابی کن → اگر هنوز good/great → VIP

### 3) VIP آلارم ویژه — متعلق به همین بخش

**قبل:** VIP جدا برای کلمه کلیدی ستاره‌دار

**حالا:** VIP جزو شکارچی است — وقتی شکار good/great پیدا شد:

- **بدون مذاکره:** اگر اطلاعات کامل است و شکار است → فوری `hunter_vip` event + تلگرام با آنالیز:
  ```
  ⭐ شکار ویژه
  پراید 1399
  قیمت: 250,000,000 تومان
  منصفانه: 303,800,000
  بازار سالم: 310,000,000
  تخفیف: 17.7%
  سطح: great | اطمینان: 0.75
  لینک: https://divar.ir/v/xxx
  ```

- **با مذاکره:** بعد از چانه، اگر توافق شد:
  ```
  ⭐ شکار ویژه — بعد مذاکره
  قیمت اولیه: 300M
  بعد مذاکره: 250M
  منصفانه: 320M
  تخفیف نهایی: 21.9%
  مذاکره: فروشنده: باشه قبوله 240 میلیون | من: ممنون...
  ```

**پیاده‌سازی:**
- `monitor.py` → `_score_hunter()` → اگر good/great → `build_vip_payload()` → `emit("hunter_vip")` + `_vip_hunter_alert()` → تلگرام/بله/روبیکا
- `nlu.py` → `_apply_hunter_reply()` → اگر پاسخ مذاکره توافق بود → دوباره VIP
- `web/server.py` → `/api/hunter/vip` → لیست شکارهای ویژه
- `/api/hunter/analyze/{token}` → تحلیل کامل یک آگهی + تاریخچه مذاکره
- `/api/hunter/negotiate/{token}` → شروع مذاکره دستی

### 4) انعطاف و حرفه‌ای بودن

- **برای هر دسته:** vehicle, phone, laptop, appliance, generic — هر کدام adjustments جدا + research_note
- **قابل توسعه:** کاربر در تنظیمات پیشرفته می‌تواند آپشن جدید اضافه کند (مثلاً «باتری تعویض» -۸%، «کف‌خواب» -۵%)
- **اینترنت:** `identify_product` آماده برای web search است — در نسخه بعدی می‌تواند با `fetch_market_price_from_web` قیمت بازار را از اینترنت بگیرد (فعلاً با median محلی کار می‌کند ولی اینترفیس آماده است)
- **مدل هماهنگ:** همه جا `is_ready()` چک می‌شود — اگر Qwen آماده باشد، متن انسانی با مدل، وگرنه fallback قاعده‌ای هوشمند — سیستم هرگز نمی‌خوابد

### 5) پیام‌های ثابت — بخش جدا

- پیام‌های خودکار عادی (SMS/چت برای شماره‌یاب) ثابت هستند — قالب با متغیر `{title} {city} {price} {greeting} {closing}` + گردونه هر بار متفاوت → ضد اسپم
- این بخش جدا از مذاکره شکارچی است — در `chat.py` و `sms.py` با `compose_chat` و `maybe_send_for_lead`

## الگوریتم پیشنهادی نهایی (خلاصه)

```
1. شناسایی محصول از عنوان+متن (regex + LLM fallback)
2. جمع‌آوری 80 نمونه اخیر همان کلمه/شهر/پلتفرم (دیوار+شیپور+رینگ اگر فعال)
3. برای هر نمونه: استخراج flags + mileage + year → adj → healthy_eq = price/(1+adj)
4. فیلتر پرت IQR روی healthy_eq → healthy_median, p10, p25, p75, mean, std
5. برای آگهی هدف: flags + mileage_adj + year_adj → total_adj → fair = healthy_median*(1+total_adj)
6. discount = (fair-price)/fair → level (good 10%, great 18%, suspicious 48%) + تقویت با p10
7. confidence بر اساس count + missing + flags
8. اگر missing بحرانی → pending → استعلام انسانی با مدل
9. پاسخ → fill_from_reply → دوباره ارزیابی
10. اگر good/great و confidence≥0.5 → مذاکره:
    - opener → offer → final (حداکثر 3 دور)
    - هر پیام انسانی با مدل، فروشنده نفهمد ربات است
    - تحلیل پاسخ → اگر توافق یا قیمت جدید خوب → VIP
11. VIP آلارم ویژه با تمام جزئیات + تاریخچه مذاکره → تلگرام/بله/روبیکا
```

## فایل‌های جدید/تغییر

- `hunter_analyzer.py` — آنالیزور حرفه‌ای بازار سالم + IQR + اطمینان + شناسایی محصول + قیمت وب اختیاری
- `hunter_negotiator.py` — مذاکره‌گر انسانی چندمرحله‌ای + VIP payload
- `price_knowledge.py` — **جدید**: هوک قیمت از وب (Torob API سبک) + کش ۲۴ساعته + fallback امن
- `hunter.py` — حالا از analyzer استفاده می‌کند، fallback قدیمی حفظ
- `db.py` — ستون‌های جدید: negotiation_status, negotiated_price, negotiation_history, hunter_confidence, fair, discount, market_median
- `nlu.py` — _apply_hunter_reply با مذاکره + VIP
- `monitor.py` — _score_hunter حرفه‌ای + _maybe_hunter_negotiate + drain_hunter_negotiate + _vip_hunter_alert
- `web/server.py` — /api/hunter/analyze/{token}, /api/hunter/negotiate/{token}, /api/hunter/vip
- `web/static/index.html` — تب VIP حرفه‌ای + تحلیل + مذاکره + نمایش fair/market/discount/confidence
- `cli.py` — دستورات جدید: `hunter`, `hunter-negotiate`, `hunter-vip`
- `nlu_engine.py` — 27 تست (قبل 24) + analyzer + negotiator
- `tests/test_full_system.py` — 25 تست + analyzer + negotiator
